# V8 Locked Input Evidence Pack

This note documents an additive input-evidence pack for the permanent Look
Twice V8 one-shot result. It improves judge-facing reproducibility without
running the model, opening the locked split again, changing a threshold, or
rewriting the authoritative locked report.

## Contents checked

The verifier checks the whole-archive SHA256 before inspecting its table of
contents. It then parses only the 3,600 JSON records inside the tar stream; it
does not extract any member or load an array.

- 400 seed directories, exactly `102100` through `102499`;
- 400 `_COMPLETE__<seed>.json` markers;
- 3,200 metadata records, eight per seed;
- 3,200 members of each required type: RGB, noisy depth, clean depth, entity
  segmentation, obstacle mask, and corridor mask;
- 1,560 blocked and 1,640 clear labels;
- one recorded generation commit:
  `9f48acb8eec4a8ed84d058e2976dd9a0940debf6`;
- relative, traversal-free member and metadata paths, with no machine-local
  absolute locations.

RGB, noisy depth, and corridor mask are runtime-legal model inputs. Clean
depth, entity segmentation, obstacle masks, and offline labels are evaluation
or label-generation artifacts and remain forbidden to the runtime. Their
presence makes the input package auditable; it is not a claim that inference
consumed them.

## What this pack establishes

- A byte-identified 400-world, 3,200-record input and label population exists
  for the exact seed range named in the permanent report.
- Each metadata record names all six required members with relative paths and
  recorded SHA256 fields.
- The archive and sidecar bytes match the locally preserved identities.
- The immutable locked-open seal and permanent locked-report files still
  match their established SHA256 identities.

## What it does not establish

This archive does **not** contain the original one-shot per-sample model
predictions. It also does **not** contain the 24 raw live full-chain episode
JSON files. The permanent report contains 24 row summaries, but those
summaries are not a substitute for the raw episodes.

Consequently, this verifier does not recompute the reported `1.000` offline
metrics and does not claim that it can reconstruct the original one-shot
execution. If original prediction or episode files are later recovered, they
must be published as a separately hashed additive evidence pack. They must not
be regenerated by rerunning the locked split and described as original
one-shot outputs.

## Verification

Use Python 3.11 or newer. No GPU, PyTorch, Genesis, Go service, or third-party
Python package is required.

```bash
python3 scripts/verify_v8_locked_input_pack.py \
  --archive /path/to/v8-spatial-dataset-v1__locked_test__400seeds__20260720T120737Z.tar.gz \
  --sidecar /path/to/v8-spatial-dataset-v1__locked_test__400seeds__20260720T120737Z.sidecar.json \
  --check-only
```

Omit `--check-only` to regenerate the repository manifest. The manifest stores
only stable basenames, relative repository paths, counts, timestamps, and
hashes; command-line machine paths are never serialized.

Run the isolated tests with:

```bash
python3 -m unittest tests.test_v8_locked_input_pack -v
```
