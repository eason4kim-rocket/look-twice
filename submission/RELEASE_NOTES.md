# Look Twice V8 Competition Candidate

This release carries the public, hash-pinned assets for the English Track 3
owner-review package. It does not represent an opened competition PR.

Look Twice is a pre-action evidence-assurance layer for embodied AI. A denied
Action Contract becomes a machine-readable `BeliefGap`; a scout acquires the
missing independent view, and direct motion is authorized only when the Python
policy and standalone Purify Go core agree.

## Locked result

- 12 same-world active/passive pairs, 24 full-chain Genesis episodes;
- active direct routes: 11/12;
- passive direct routes: 0/12;
- paired direct-route gain: +91.7 percentage points;
- mission completion: 12/12 for both policies;
- unsafe crossings and unplanned fallbacks: 0/24;
- Python/Purify Go decision agreement: 24/24.

These are fixed-suite, simulation-only results, not a safety certification.
Seed 102105 remained conservatively denied and detoured and is retained in the
denominator.
